# 🌍 AI-Powered Language Learning Application

AILo is an innovative mobile application that combines personalized language learning experience, social interaction, and artificial intelligence technologies. Our goal is to move away from traditional memorization methods and provide a modern and fun learning environment that increases users' active participation and motivation.

## ✨ Key Features

- ✅ **Smart Vocabulary Lists**: Frequently used and thematically categorized word groups. Ability to create, edit, and share your own vocabulary lists. Quick preview, sorting, and filtering options on lists.
- 🧠 **AI-Powered Language Coach**: Analyzes users' learning habits. Offers personalized study plans and vocabulary suggestions. Provides targeted repetition and practice suggestions for weak areas.
- 🗣️ **Speech Diary**: Users can create daily voice recordings. Artificial intelligence gives instant feedback on pronunciation and fluency. Visuals and statistics that track progress over time.
- 👥 **Real-Time Community Interaction**: Users can listen to and comment on each other’s speech diaries. Group chats and community events encourage social learning. “Language partner” matching allows practice with users who have similar goals and levels.
- 🤝 **“Dil Partneri” Eşleştirmesi**: Benzer seviyede ve hedefte kullanıcılar otomatik olarak eşleştirilir.
- 📷 **Object Recognition with Camera**: Objects in the environment are identified using the phone camera. Provides the object's equivalent in the target language, pronunciation, and example sentences. An integrated learning experience with the real world that strengthens visual memory.
- 📊 **Language Development Tracking**: Vocabulary knowledge, speaking skills, and learning habits are tracked with detailed graphs. Personalized achievement badges and motivational notifications.
- ⚙️ **Secure and User-Friendly Login/Registration System**: Secure login with email/password and social media. Password recovery, session management, biometric authentication. Modern, accessible, and smooth user interface.

  ## RoadMap ##
  - Offline usage support
  - Lesson modules based on language level
  - GPT-powered conversation simulation
  - Gamification (badges, points, etc.)
